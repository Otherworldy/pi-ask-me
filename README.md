# pi-prompt

口语任务先问再做。不改用户原文，不拦截输入。主 agent 自己在对话里提问。

## 做什么

新任务回合在 system prompt 里加一段提醒：有会改变实现的歧义就用用户的语言问（最多 3 问），等回答；没歧义就直接干。

续上、纠错、回答问题的回合改成「别重新采访，继续做」。

## 不做什么

- 不改写原文
- 不弹窗、不另开一轮无工具模型
- 不硬拦 `write`/`edit`/`bash`（弱模型可能仍直接动手）

## 命令

```
/prompt          状态
/prompt on       开启（默认）
/prompt off      关闭
/prompt once     下一条按新任务提醒先问
```
